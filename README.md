## Commands (PowerShell)
```powershell
npm install
npm run dev        # local dev
npm run build      # production build to dist/
npm run preview    # preview the build
```
## GitHub Pages
1. Push to a GitHub repo on the `main` branch.
2. Repo Settings → Pages → Source: **GitHub Actions**. The included workflow deploys on every push.
3. If the repo is not `<username>.github.io`, `base: './'` in `vite.config.js` works as-is.
